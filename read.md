# 💳 CreditSmart - Sistema de Gestión de Solicitudes de Crédito

## 📘 Descripción del Proyecto
**CreditSmart** es una plataforma web desarrollada para **FinTech Solutions S.A.S**, que permite a los usuarios **consultar opciones de crédito**, **simular préstamos** y **solicitar créditos en línea** de manera sencilla.  

Este proyecto corresponde a la **Evidencia S20 - EA1: Diseño de Interfaces Web** del curso **Ingeniería Web I**.  
En esta etapa, el objetivo es **diseñar las interfaces visuales**, sin necesidad de implementar funcionalidad real o conexión a base de datos.

---

## 🧭 Contenido del Proyecto

El sistema está compuesto por tres páginas principales:

### 1. 🏠 Inicio - Catálogo de Créditos
- Muestra los productos crediticios disponibles en **cards** con:
  - Imagen representativa
  - Nombre del producto
  - Tasa de interés anual
  - Monto mínimo y máximo
  - Plazo máximo
  - Botón “Ver detalles” o “Solicitar”
- Los productos se muestran con datos fijos (estáticos).

### 2. 📊 Simulador de Crédito
- Permite al usuario:
  - Buscar créditos por nombre.
  - Filtrar por rango de monto (usando opciones predefinidas).
  - Visualizar resultados en tarjetas.
- El filtro y búsqueda son **solo visuales**, sin lógica funcional real.

### 3. 📝 Solicitar Crédito
- Contiene un formulario para simular el registro de una solicitud de crédito.
- Secciones del formulario:
  - **Datos personales**: nombre, cédula, correo, teléfono.
  - **Datos del crédito**: tipo, monto, plazo, destino.
  - **Datos laborales**: empresa, cargo, ingresos.
- Incluye botones:
  - `Enviar Solicitud` (sin acción funcional).
  - `Limpiar Formulario`.
